# hf_to_cc — from Hartree–Fock to coupled cluster

A hands-on route through quantum chemistry, from the variational principle to coupled cluster. Every method is derived in the notes one step at a time, nothing waved through, and then implemented in a few dozen lines of NumPy that follow the formulas line for line; "Formula ↔ code" boxes in the notes show the two side by side. If wave-function methods interest you and you want to see how the equations become working code, without much background in theory, programming or the math behind it, this is written for you. Every number is checked against PySCF.

**Coming next** (in progress or planned):
- more coupled cluster: CCSD, CCSD(T) and EOM-CCSD, with the equations generated by [ccgen-wick](https://github.com/Heisenbergnox/ccgen-wick);
- configuration interaction: full CI on determinant bit strings, with a Davidson solver;
- open shells beyond UHF: UMP2, UCCSD, and SCF stability analysis;
- speed: vectorized spin-orbital integrals, cache-friendlier array layouts and contraction orders, and spin-adapted closed-shell versions of the correlated methods.

## What's inside

| `hf_to_cc/ao2mo.py` | AO→MO transformation, antisymmetrized spin-orbital integrals |
| `hf_to_cc/mp2.py`, `ccd.py` | MP2 and spin-orbital CCD |

| `tests/` | checks against PySCF and reference values |
| `examples/` | water (`run_h2o.py`), plain SCF vs DIIS (`diis_vs_plain.py`), all 15 molecules (`molecules.py`) |

These runs and the 37 tests were done on two Linux machines (Ubuntu 26.04; AMD Ryzen AI Max+ 395 and AMD Ryzen 9 9955HX) with Python 3.14, NumPy 2.5, SciPy 1.18, PySCF 2.13 and pytest 9.2.

## What the molecule runs taught me

- **DIIS finds the stationary point nearest to where it starts.** For N₂ from the core Hamiltonian that is a solution 0.69 Eh too high, so the SCF now takes a starting density, and `guess_density` gives the atomic-density guess.
- **Orbital energies come from the Fock matrix of the converged density, not from the DIIS mixture.** H₂ converged in two iterations with the wrong orbital energies, and MP2 came out wrong with them.
- **Plain SCF can bounce forever.** For water with both O–H bonds stretched to 1.87 Å, the energy alternates between two values; DIIS converges in about 14 iterations. Started from the core Hamiltonian instead of the atomic-density guess, DIIS can even land on different solutions on different machines, so the examples and tests start from the atomic-density guess.
- **UHF has several solutions.** `uhf_diis` converges for all 44 cation runs, but which solution it lands on depends on the starting orbitals. Telling which one is lowest needs a stability analysis, which is on the list above.

Chapters 5 and 6 of the notes have the numbers.

## Usage

Python 3 with NumPy, SciPy and PySCF (for the AO integrals and the reference values in the tests), plus pytest for the tests. From the repository root:

```
pip install numpy scipy pyscf pytest
python examples/run_h2o.py
python examples/diis_vs_plain.py
python examples/molecules.py
python -m pytest tests
```
